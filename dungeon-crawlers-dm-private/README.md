# Dungeon Crawlers — Dungeon Master Chronicle

This is the private local Dungeon Master companion for Dungeon Crawlers. It contains story material imported from `The Story.xls` and `the side quest.xls`.

## Open the Chronicle

Double-click `index.html`. The site runs locally and does not publish campaign spoilers online.

## During a session

- Select locations from the campaign library.
- Change enemy health and encounter status.
- Cycle discoveries through Hidden, Revealed and Found.
- Cycle abilities through Hidden, Revealed and Learned.
- Write improvised details in Quick Notes.
- Use connected route buttons to move to another location.

All session changes save automatically in that browser on that Mac.

## Add or change content

Use **Edit location** to change story text, DM notes, enemies, discoveries, abilities or routes. Use the plus button beside Campaign Library to create a completely new area.

New and edited areas are stored locally. They do not modify the original Excel workbooks.

## Protect your work

Use **Download backup** after sessions or substantial edits. This produces a JSON backup containing the full campaign library and all current encounter states. **Restore backup** can load it again later.

Keep the DM Chronicle private: it includes story spoilers, secrets and encounter details.
